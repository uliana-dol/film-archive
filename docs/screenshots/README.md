# Скріншоти результатів лабораторної №2

У цій папці зберігаються **лише фактичні знімки екрана** після запуску експериментів. Скріншоти не замінюються демонстраційними зображеннями або прикладами, які не були отримані на власній інфраструктурі.

## Що зберегти

| Назва файлу | Що повинно бути видно |
|---|---|
| `dashboard.png` | П'ять графіків CloudWatch за одним проміжком часу |
| `load-start.png` | Момент початку k6 |
| `cpu-threshold.png` | Перетин CPU цілі 60% |
| `scale-out.png` | Збільшення кількості API EC2 |
| `scale-in.png` | Повернення до поточного мінімуму |
| `sns-confirm.png` | Підтверджений SNS email (без токенів) |
| `alert-high.png` | Реальний лист ALARM |
| `alert-ok.png` | Реальний лист OK |
| `queue-worker.png` | Черга SQS і масштабування worker 0→1→0 |
| `scheduled-actions.png` | Денна/нічна дія Auto Scaling |
| `idempotency.png` | Два однакових POST і лише один запис |

Для кожного графіка запишіть час UTC, який відповідає тесту. Перед публікацією приховайте JWT, AWS Account ID, приватні email, секрети, посилання на підтвердження підписки та персональні дані. Якщо тест ще не відбувся, відповідного PNG-файлу поки немає.
